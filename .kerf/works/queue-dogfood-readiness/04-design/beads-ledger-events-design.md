# Change Design — Beads ledger and event artifacts

## Current state

Canary selection has no structured snapshot. Event logs aid investigation only.
Scratch results are not fleet-ledger authority.

## Target state

Use the retained readiness snapshot as a tracked record or report section.
It names command, source path, capture time, candidate set, selected item, and exclusions.
It names exact event files and checks stale terminal intents.
It attaches scratch results only to the assessor report after the controlled run.

## Rationale

The record makes selection reproducible and retains Git and Beads as authority.
