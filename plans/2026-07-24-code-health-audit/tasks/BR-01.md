# BR-01 — Extract immutable RunPlan resolution

## Dispatch metadata

- Group / priority: run architecture / P0
- Execution profile: `sol_high`
- Reviewer profile: `sol_xhigh`
- Depends on: `ARCH-GATE`, `BR-00`
- Work type: serial beadRunOne decomposition

## Objective

Extract workflow, harness, model/provider, branching, repository, sandbox
profile, and placement decisions from `beadRunOne` into a deterministic
`ResolveRunPlan` owner. Resolution performs no durable or process effects.

## Exclusive lease

The resolution sections of `workloop.go`, existing resolver files/pure packages,
one target owner from `BR-00`, and focused tests. Sole `dispatch_spine` writer;
the architecture baseline is coordinator-owned.

## Required work

1. Capture all required inputs before resolution; no daemon config/global reads
   inside the pure resolver.
2. Represent queued/direct and single/review/DOT variants explicitly.
3. Preserve current precedence and refusal rules with exhaustive tables.
4. Delete duplicate inline resolution and compatibility fallbacks.
5. Meet the exact per-task target approved by `ARCH-01` before this card becomes
   ready.

## Acceptance

- Equal inputs yield equal `RunPlan` or typed refusal.
- Invalid plan combinations cannot be constructed.
- Resolution has zero filesystem, ledger, event, network, or process effects.
- All production call paths consume the same resolver.

## Verification

Table/property/mutation tests, production-path composition test, architecture
gate, delta lint, UBS, and `make check-fast`.

## Escalate when

Stop for a contract amendment if production relies on resolution after a
resource is acquired or a mutable fact cannot be safely snapshotted.

## Return

Use the directory return contract. **COMMIT EXPLICITLY.**
