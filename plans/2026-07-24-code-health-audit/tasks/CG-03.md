# CG-03 — Prove the real production composition

## Dispatch metadata

- Group / priority: run architecture / P0
- Execution profile: `terra_high`
- Reviewer profile: `sol_xhigh`
- Depends on: `CG-02D`
- Work type: production-graph fidelity proof

## Objective

Add a bounded test that assembles through the real CLI/daemon composition root
with controlled external adapters and proves required queue, Run, mode,
process, terminal, and recovery owners are the same graph production uses.

## Exclusive lease

One production-composition test/harness, controlled adapters, and gate wiring.
No production semantics.

## Required work

1. Construct the graph using the real production assembly function.
2. Assert all required owners and dependency directions.
3. Run one non-Pi queue item through reservation, claim, Run, mode execution,
   terminalization, and restart inspection.
4. Mutate/remove each load-bearing wiring edge and prove the test fails.
5. State exactly which OS/network/primary-daemon facts remain deferred.

## Acceptance

- `StartForTesting` cannot silently build a different graph.
- Missing or miswired mode/terminal/process owners are detected.
- The scenario is hermetic and deterministic.
- `E2E-BASE` extends this proof rather than inventing another harness.

## Verification

Composition scenario, mutation matrix, race/repeat, architecture/depguard
gates, lint/UBS, and `make check-short`.

## Escalate when

Stop if the only proof requires the primary daemon or real remote services.

## Return

Use the directory return contract. **COMMIT EXPLICITLY.**
