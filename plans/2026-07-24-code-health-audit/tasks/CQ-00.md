# CQ-00 — Characterize the supported queue lifecycle

## Dispatch metadata

- Group / priority: core queue / P0
- Execution profile: `terra_high`
- Reviewer profile: `sol_xhigh`
- Depends on: `CQ-00A`, `CQ-00B`
- Work type: read-only deterministic evidence inventory

## Objective

Synthesize and independently challenge the two mechanical inventories into
`tasks/evidence/CQ-00.yaml`: a reviewed source-and-test map of every supported
queue admission path through durable state, dispatch stamp, terminal update,
shutdown, restart, and recovery. Do not change production behavior.

## Evidence to verify first

Trace symbols, not comments alone:

- CLI: `internal/queue/cli` submit, append, resume, cancel, status.
- Socket/composition: `internal/queue/rpc.go` `HandlerAdapter` and
  `internal/daemon/bootsocket.go`.
- Persistence: `Persist`, `Load`, `MigrateFromLegacy`,
  `CompleteAndUnlink`, `CancelQueueOnShutdown`.
- In-memory owner: `internal/daemon/queuewiring` and every direct `Persist`
  caller found by `rg`.
- Dispatch/recovery: `snapshotFleet`, dispatch stamp and group advance in
  `internal/daemon/workloop.go`, startup queue loading/reconciliation, and
  queue scenario tests.

## Exclusive lease

- `tasks/evidence/CQ-00A.yaml` and `tasks/evidence/CQ-00B.yaml`
- Read any source/test/spec needed to challenge them.
- Write only `tasks/evidence/CQ-00.yaml`.
- Do not edit production code, tests, the task index, or another evidence file.

## Required work

1. Reconcile duplicates and contradictions between the ingress/caller and
   test/crash-cut inventories.
2. Sample every production composition root and every direct `Persist` caller.
3. Record crash cuts and ownership gaps in a single reviewed matrix.
4. Record contradictions between specs and production without selecting a new
   contract.

## Acceptance

- Every `Persist` call is accounted for.
- CLI and socket paths are distinguished from direct test/helper paths.
- The artifact names exact missing tests and the smallest credible ownership
  boundary for each gap.
- No statement says “safe,” “supported,” or “atomic” from a comment alone.

## Verification

- Run the narrow queue package tests only if needed to validate a mapping.
- Validate the evidence YAML parses.
- Frontier reviewer independently samples all production composition roots and
  either approves or corrects the map.

## Escalate when

Stop and report if an ownership boundary cannot be determined from durable
source/tests. Do not infer or implement a contract.

## Return

Return the evidence path and reviewer findings. No production commit is
required; commit the evidence artifact explicitly when the coordinator accepts
it.
