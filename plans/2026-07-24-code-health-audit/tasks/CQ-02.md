# CQ-02 — Settle the queue transaction and durability contract

## Dispatch metadata

- Group / priority: core queue / P0
- Execution profile: `sol_xhigh`
- Reviewer profile: `sol_xhigh`
- Depends on: `CQ-00`
- Work type: kerf/spec design; no production implementation

## Objective

Produce a reviewed normative contract for queue mutation, persistence, install,
generation/locking, completion/shutdown, migration, and crash recovery. This
task makes the design decision once; it does not modify production behavior.

## Evidence to verify first

- `internal/queue/persistence.go` `Persist`, `Load`, `MigrateFromLegacy`,
  `CompleteAndUnlink`, `CancelQueueOnShutdown`, `writeTempAndClose`, `fsyncDir`.
- `CQ-00` caller inventory and `specs/queue-model.md` QM-001/QM-002/QM-063.
- Confirm the current `MigrateFromLegacy` “destination exists” branch does not
  validate the destination before removing legacy state.

## Exclusive lease

- the project-local kerf work and normative queue/reconciliation specs selected
  by the planning pass
- write no production code or tests

## Required work

1. Write a crash/fault matrix for create, write, file sync, close, rename,
   directory sync, legacy removal, and final directory sync.
2. Choose one mutation owner and define generation/CAS or single-process lock
   guarantees explicitly.
3. Define clone → mutate → persist → install ordering and error visibility.
4. Define one-valid-copy migration and terminal/shutdown failure behavior.
5. Produce exact implementation slices and compatibility/migration rules.

## Acceptance

- Normative text decides every crash cut and memory/disk ordering question.
- The design is reviewed for compatibility with current files and startup.
- Implementation slices have non-overlapping leases and failing-first oracles.

## Verification

Kerf/spec validation and independent `sol_xhigh` durability review.

## Escalate when

Surface any operator decision about file-format compatibility or multi-process
writers. Do not implement through uncertainty.

## Return

Return the finalized contract and implementation slices. **COMMIT EXPLICITLY.**
