# JR-03 — Keep terminal state and claim release consistent

## Dispatch metadata

- Group / priority: job/run / P0
- Execution profile: `sol_xhigh`
- Reviewer profile: `sol_xhigh`
- Depends on: `CQ-RUN-WAIT`, `CQ-04`, `JR-01`, `JR-02`, `BR-03`,
  `CQ-CALLER-GROUP-ACTIVATION`
- Work type: serial terminal-spine correctness

## Objective

Implement the terminal owner defined by `BR-00` after a typed mode result:
enforce ordering across Run terminal decision, Bead close/reopen, queue item
terminal persistence, group advance, unlink, and claim release. Delete the
superseded inline terminal blocks.

## Exclusive lease

- the typed terminal owner and adapter boundary defined by `BR-00`
- only the old terminalization/group-advance regions of `workloop.go` required
  to delete superseded paths
- `internal/runloop/runbridge.go` only if the reviewed contract requires it
- focused terminal fault/restart tests
- `drainCancelledQueue` durable shutdown transitions and focused tests
- `evaluateGroupAdvanceWithOutcome`, QM-053 terminal call sites, and terminal
  claim-release composition

## Acceptance

Cover close failure, reopen failure, queue-persist failure, completed-persist
then unlink failure, and shutdown. No outcome leaves durable terminal state and
claim/queue ownership silently inconsistent; restart converges without rerun.
Shutdown drain uses the same terminal owner rather than an inline mutation path.
Final success invokes the receipt primitive once; failed-group terminal and
`paused-by-failure` commit together before observations. Missing optional
observations cannot hang `CQ-RUN-WAIT`; shutdown emits no operator audit.

Accepted intermediate: only this integration may enable crash-optional final
observation after waiter and startup recovery land. Roll back JR-03 terminal
composition only; rolling back `CQ-04` or `CQ-RUN-WAIT` first requires
disabling receipt-producing call sites.

## Verification

Fault matrix, race/restart scenarios, lint/UBS, Sol review, check-fast.

## Escalate when

Stop for a spec decision if no ordering can preserve both Bead and queue truth
under partial failure.
