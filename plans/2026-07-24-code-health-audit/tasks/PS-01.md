# PS-01 — Own one process and session phase scope

## Dispatch metadata

- Group / priority: run architecture / P0
- Execution profile: `sol_xhigh`
- Reviewer profile: `sol_xhigh`
- Depends on: `ARCH-01`, `PI-L1B`, `PI-L1C`, `PI-F0`
- Work type: shared lifecycle owner

## Objective

Define and implement the pure lifecycle protocol for one agentic phase:
unbound → bound → ready/running → terminal → closed, including terminal latching,
cancel, signal, wait, join, and idempotent close. `ARCH-01` chooses the owner
name and package; this task does not preselect either.

## Exclusive lease

One pure lifecycle owner chosen by `ARCH-01` and focused state-machine tests. No
tmux/substrate adapter, remote capability, or workloop/reviewloop/DOT call-site
integration.

## Required work

1. Define one Start/Bind/Signal/Wait/Close ownership protocol.
2. Compose the reviewed terminal latch, ProcessExit finalizer, and bounded
   TERM/KILL/wait/reap owners rather than reimplementing them.
3. Define required effect capabilities without implementing their adapters.
4. Make close/idempotence and ownership transfer explicit.
5. Provide fakes that preserve lifecycle ordering instead of skipping it.

## Acceptance

- Exactly one owner calls Wait and exactly one close path releases resources.
- Signal-before-bind, cancel-during-ready, exit-before-watcher, and repeated
  close converge safely.
- The abstraction does not contain workflow, queue, review, or DOT policy.
- No workflow, queue, adapter, transport, or remote policy enters the owner.

## Verification

State-machine/property/mutation tests, race/repeat, depguard, delta lint, UBS,
and `make check-fast`.

## Escalate when

Stop if the protocol requires workflow-specific policy or cannot assign one
Wait/close owner.

## Return

Use the directory return contract. **COMMIT EXPLICITLY.**
