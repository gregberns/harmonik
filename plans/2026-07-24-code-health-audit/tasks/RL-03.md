- Group / priority: run architecture / P0
- Execution profile: `sol_xhigh`
- Reviewer profile: `sol_xhigh`
- Depends on: `RL-02C`, `BR-00`
- Work type: serial reviewloop state-machine decomposition

## Objective

Extract implementer and reviewer phase shells around the shared phase scope,
leaving a thin iteration coordinator that consumes reviewcycle decisions.
Reduce `runReviewLoop` below the architectural target before any package move.

## Exclusive lease

`reviewloop.go`, exact new phase-shell files, focused tests, and architecture
baseline. Sole `reviewloop_spine` writer. A file move is separately gated.

## Required work

1. Extract implementer launch/ready/run/finalize into one typed phase.
2. Extract reviewer launch/ready/verdict/finalize into one typed phase.
3. Keep iteration policy in reviewcycle and continuity in its existing owner.
4. Remove duplicated launch/wait/cleanup and terminal mapping.
5. Make the remaining coordinator small enough for a compile-probed move.

## Acceptance

- Phase shells share lifecycle but not mutable local state.
- The coordinator expresses iteration order only.
- No new god interface or daemon back-edge is introduced.
- Complexity/span meet the reviewed `ARCH-01` target.

## Verification

Implementer/reviewer phase matrices, restart/continuity tests, local
real-process test, race/repeat/leak, architecture gate, lint/UBS, and
`make check-short`.

and does not require the LIFT.12/LIFT.13 operator gate; record whether the
reviewed architecture resumes or supersedes L8.
